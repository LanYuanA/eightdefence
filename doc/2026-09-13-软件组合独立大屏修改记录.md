# 软件组合独立大屏修改记录

日期：2026-09-13

开发位置：项目根目录，agent 分支。

## 本轮交付

保留原任务编排界面及拖拽、服务参数配置、应用生成能力，将应用运行部分调整为“应用中心 → 独立应用”。每个应用内部只有返回应用中心的导航，不提供跨应用页签；返回中心不会停止后台任务。

独立应用采用无滚动大屏：中央放置四层圆形节点调用图，左侧展示感知数据和执行设备，右侧展示任务阶段和服务返回值，底部展示事件流及日志。感知数据、服务返回值和历史日志可分页查看；日志可导出为 JSON。

调用关系按应用服务配置生成：硬件 → 设备抽象 → 原子服务 → 应用，并展示指令下发及状态返回。已选用服务高亮，未选用服务显示为灰色节点，节点支持悬停和点击查看信息。线路绕开灰色节点，避免误解为调用了未选用服务。任务编排中的原有船舶示意保留，独立应用中央不再放船。

## 持续流动规则

- 应用运行时，全部已选用链路循环显示粒子，不随某个服务完成而消失。
- 一轮任务完成后继续播放链路动画。
- 应用暂停、取消、执行失败或网关失联时停止动画。
- 动画仅展示调用关系，不循环执行后台任务、不重复下发设备指令，也不是实际数据包流量统计。
- 页面用“链路循环展示”标记动画；任务状态和事件日志仍显示真实调度结果。

## 状态与数据

各应用通过独立应用标识读取任务状态、服务结果和事件。应用可同时运行，暂停其中一个不影响其他应用。网关历史运行按编号自然排序，避免 RUN-10 被误认为早于 RUN-9。

首次无法连接网关时保留本地演示；已经连接后失联，不切换为本地模拟执行，而是禁用应用启停操作、停止粒子并等待恢复。

感知读数来自 /api/data；服务结果来自 /api/v1/marine。结果标注演示数据、模拟执行或实时采集等来源，离线传感器显示“—”。通风、报警、排水目前仍为模拟执行；本轮浏览器验证使用后端演示模式，没有验证真实电机动作。

含 M01 的应用保留电机参数窗口及急停入口，是否控制真实电机取决于网关运行模式。
