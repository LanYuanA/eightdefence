## 一、修复日志查看失败问题

### 问题描述

在主控台点击"系统日志"进入日志页面后，日志文件列表可以正常加载，但点击任意日志文件时内容显示"加载日志文件失败"。

### 根因分析

`application/web_server.cpp` 第 323 行存在**偏移量错误**。

后端处理 `GET /api/logs/{filename}` 请求时，从 HTTP 请求行中提取文件名的起始位置有误：

```cpp
// 修改前（错误）
size_t start = 13;

// 修改后（正确）
size_t start = 14;
```

字符串 `"GET /api/logs/"` 长度为 14 个字符（索引 0~13），尾部 `/` 位于索引 13。原代码从索引 13 开始截取，导致文件名始终以 `/` 开头（如 `/gateway.log`）。随后路径穿越安全检查 `filename.find("/")` 命中，所有请求均被返回 **403 Forbidden**。

### 修改文件

- `application/web_server.cpp` 第 323 行

## 二、安防应用前端改造（HTML → Vue）

### 改造背景

安防应用原有前端为独立 HTML 文件（`public/apps/security/index.html`），采用纯 JavaScript 模拟数据，未对接后端 API，且与 Vue 主工程分离，不便于统一开发和维护。

### 改造内容

将安防应用前端从独立 HTML 改造为 Vue 单文件组件（SFC），对接后端真实 API。

#### 新建文件

- `ui/src/views/Security.vue` — 安防系统监控页面

#### 页面结构

| 区域 | 说明 |
|------|------|
| 顶部导航栏 | 与主控台/设备管理/日志页面一致的通用导航 |
| 系统概览 | 三个状态卡片：系统整体状态、报警服务状态、防护处置状态 |
| 应用卡片 | 水浸风险安防、人员入侵检测、有害气体安全防护（含模拟/恢复按钮） |
| 服务状态 | 报警服务、防护处置服务的实时状态 |
| 基础硬件层 | 6 个硬件设备卡片展示 |
| 系统事件日志 | 实时日志滚动区域，按级别着色 |

#### 数据对接

| 功能 | API | 说明 |
|------|-----|------|
| 状态轮询 | `GET /security/api/status` | 每 2 秒刷新，与后端轮询线程同步 |
| 日志轮询 | `GET /security/api/logs?limit=50` | 每 5 秒刷新 |
| 模拟异常 | `GET /security/api/control?action=simulate&target=X` | 支持 water/intrusion/gas 三种目标 |
| 恢复正常 | `GET /security/api/control?action=reset&target=X` | 支持 water/intrusion/gas 三种目标 |

## 四、Vite 代理配置补充

### 修改文件

- `ui/vite.config.ts`

新增 `/security` 路径代理，指向 `http://localhost:8080`，使开发模式下安防 API 请求可正常转发到后端。

```typescript
proxy: {
  '/api': {
    target: 'http://localhost:8080',
    changeOrigin: true
  },
  '/security': {           // 新增
    target: 'http://localhost:8080',
    changeOrigin: true
  }
}
```

## 验证方式

1. 重新编译后端：`make`
2. 启动后端：`./app_gateway`（需在项目根目录运行）
3. 开发模式：`cd ui && npm run dev`
4. 验证日志页面：点击日志文件，确认内容正常加载
5. 验证安防页面：点击导航栏"安防系统"按钮，确认页面渲染正常、模拟/恢复按钮功能正常
