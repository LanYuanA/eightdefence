# 软件组合独立应用大屏使用说明

## 页面关系
任务编排已恢复原界面，保留服务库、拖拽、参数配置及生成操作。
进入路径：任务编排 → 应用中心 → 独立应用。
应用内部只提供“返回应用中心”，不直接跳转其他应用。返回不会停止应用；需要停止时点击右上角“停止”。

## 启动与演示
1. 在项目根目录 /home/kylin/ylz/work/eightdefence 启动现有网关，打开 http://127.0.0.1:8080/。
2. 开发预览：进入 ui 执行 `npm run dev -- --host 127.0.0.1 --port 5199`，打开 http://127.0.0.1:5199/。
3. 使用原任务编排的两个检修预设生成应用，或点击“一键演示”。
4. 在“应用中心”进入应用，右上角启动、暂停、继续或停止当前应用。
5. 返回中心再进入另一个应用，展示同时运行。暂停一个应用不会暂停另一个。

## 大屏模块
- 中央为四层圆形节点：硬件 → 设备抽象 → 原子服务 → 应用。蓝色粒子表示数据上报，金色表示指令下发，绿色表示反馈返回。暂停时停止粒子。
- 选用服务高亮，未调用服务作为原子服务层的灰色圆形节点。点击或悬停查看服务信息。
- 左侧是本应用的感知读数和执行设备状态。离线读数显示“—”，感知项较多时翻页查看。
- 右侧是任务阶段及服务返回值、来源、详情，返回值可分页查看。
- 底部是本应用的事件流和日志，可翻阅较早事件、导出 JSON。导出包含应用标识、运行状态、事件及返回值。
- 含 M01 的应用保留电机参数窗口，可在运行中下发转速、正反转或停止电机，并保留急停入口。

## 场景
夜间检修：活动、光照、烟雾、水浸并行 → 通风 → 报警 → 排水。
异常处置：烟雾、水浸、活动并行 → 报警与通风并行 → 排水。
时长和参数沿用任务编排配置，同阶段全部完成后进入下一阶段。

链路动画独立于单个服务的执行时长：启动后，全部已选用链路持续循环，一轮任务完成后仍继续展示。暂停、停止、异常或网关失联时停止动画。粒子是调用关系的可视化，不代表重复执行，也不代表实时数据包计数；查看真实执行状态请看任务阶段和日志。

## 数据边界
应用保存与执行接入现有 /api/v1/marine 网关。日志、进度、返回值和动画按当前应用标识读取。
感知读数来自 /api/data；服务返回值来自运行结果，两者分别标明来源。

网关以 --marine-demo 启动时返回后端演示数据。通风、报警、排水仍为模拟执行，不表示真实设备动作。M01 是否真实控制以网关模式为准。灰色扩展能力不代表已实现。异常处置仍需手动启动，不表示已实现阈值自动触发。

首次连接失败时使用本地演示；已连接后失联时停止动画、禁用当前应用启停操作，等待恢复，不切换成本地模拟。
刷新后从应用中心重新进入，可查看网关保存的运行状态。

## 验证
执行 `cd ui && npm run test:marine && npm run build`。
浏览器检查包括：原任务编排恢复、无跨应用入口、两应用独立运行和暂停、暂停后无粒子、日志与返回值，以及 1920×1080 和 1366×768 下模块不溢出。测试结束后停止测试应用。
