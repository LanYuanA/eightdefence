# 软软解耦领导演示优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让观看者在 10 秒内理解原子服务复用、任务组合、应用生成和多应用并行运行四项软件定义优势。

**Architecture:** 保留现有编排器和多应用运行器，通过纯模型函数生成领导演示所需的 A/B 两个独立应用；Vue 页面增加引导、复用对比、价值指标和生成动画。现有手动拖拽、传感器数据和运行逻辑保持不变。

**Tech Stack:** Vue 3、TypeScript、CSS、Node test runner、Vite

**Spec:** 用户确认的五项优化：首屏压缩、A/B 复用对比、四步引导、一键演示、生成动画。

## Global Constraints

- 应用 A 的执行服务为 `01 + 02 + 03`，应用 B 为 `02 + 03 + 04`。
- `02` 与 `03` 必须以同一服务实例定义在两个应用中复用，不复制服务实现。
- 一键演示生成两个不同应用 ID，并允许两个应用同时运行。
- 手动拖拽和顺序/并行能力继续可用。
- 页面默认软件模拟，不发送真实设备命令。
