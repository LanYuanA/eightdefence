# 电机调速原子服务设计

## 背景

船舶软件定义演示平台已经具备任务编排、并行应用运行、设备绑定、安全锁、RS485 总线、命令队列和基础电机驱动。三台电机已经通过 `/dev/ttyS9` 完成真实启停验证：地址 `0x02` 使用 IDS57-R 协议，地址 `0x0E`、`0x0F` 使用 IDS42-R 协议。

当前执行类原子服务仍返回模拟结果，真实电机驱动没有进入应用运行链路；电机参数不能在任务编排和应用运行页面配置；串口命令队列也缺少 32 位寄存器读写能力。

## 目标

- 用一个与厂商型号和总线地址无关的“电机调速控制”原子服务控制三台逻辑执行器。
- 在任务编排时配置并保存电机、转速、方向、加减速度和持续时间。
- 在应用运行时显示实际转速、状态、方向、故障和资源占用，并允许动态调速、换向、停止与急停。
- 真实设备和模拟设备使用相同的原子服务接口。
- 所有真实指令与传感器轮询共享同一串口调度链路，杜绝多个进程或旁路程序争用 `/dev/ttyS9`。
- 在演示中直观展示“应用参数 → 原子服务 → 逻辑执行器 → 设备适配器 → RS485 电机”的解耦关系。

## 非目标

- 不开放任意 Modbus 寄存器编辑。
- 不实现位置模式、回零模式或转矩模式。
- 不在设备通信失败时自动切换到模拟模式。
- 不在替换电机上线后自动恢复运动。

## 设备与逻辑能力

| 逻辑执行器 | 物理地址 | 型号协议 | 演示功能 |
| --- | --- | --- | --- |
| `EXHAUST-FAN-01` | `0x02` | IDS57-R | 机舱排烟风机 |
| `FIRE-PUMP-01` | `0x0E` | IDS42-R | 消防水泵 |
| `DRAIN-PUMP-01` | `0x0F` | IDS42-R | 舱底排水泵 |

原子服务只引用逻辑执行器标识。物理地址、型号、协议适配器、方向校准和在线状态属于设备抽象层。替换设备时更新绑定，不修改应用或原子服务。

## 协议依据

IDS42-R 与 IDS57-R 的速度模式使用相同的 CiA402 over Modbus RTU 对象：

| 寄存器 | 类型 | 用途 |
| --- | --- | --- |
| `6040h` | U16 R/W | 控制字，使能、运行和停止 |
| `6041h` | U16 R | 状态字 |
| `6060h` | U16 R/W | 运行模式，速度模式为 `3` |
| `606Ch` | I32 R | 当前速度，单位 rpm |
| `6083h` | U32 R/W | 加速度 |
| `6084h` | U32 R/W | 减速度 |
| `60FFh` | I32 R/W | 目标速度；正负号表示两个方向 |

启动序列为 `6040=0006`、`6040=0007`、`6040=000F`、`6060=0003`，随后写入加速度、减速度和目标速度。常规停止写入 `6040=0006`。所有写操作必须验证从机地址、功能码、寄存器范围和 Modbus CRC；异常响应不得记为成功。

## 原子服务契约

服务标识为 `MOTOR_SPEED_CONTROL`，输入参数如下：

```json
{
  "executorId": "EXHAUST-FAN-01",
  "speedRpm": 200,
  "direction": "forward",
  "acceleration": 10,
  "deceleration": 10,
  "durationSeconds": 10
}
```

参数规则：

- `speedRpm` 为绝对值，范围 `1～500`，默认 `200`。
- `direction` 为 `forward` 或 `reverse`。
- 设备抽象层将逻辑方向结合每台设备的 `directionInverted` 校准项，转换成 `60FFh` 的有符号 32 位值。
- 加速度和减速度使用面向操作员的逻辑值，由协议适配器转换成寄存器值。默认均为 `10`，前端只提供经过限制的范围。
- `durationSeconds` 为任务编排运行时长；停止、取消、异常和超时都会触发停机。

服务输出至少包含：服务状态、逻辑执行器、当前绑定设备、目标转速、实际转速、方向、运行状态、状态字、故障信息、占用应用、数据来源和最后更新时间。

## 后端结构

### 串口命令队列

扩展现有 `CommandQueue` 和 `AsyncBus`，支持：

- 写单寄存器。
- 写多个寄存器，承载 U32/I32。
- 读单寄存器与读双寄存器。
- 紧急停机优先级。
- 严格响应帧验证和明确错误结果。

传感器轮询、电机状态读取和电机控制必须使用同一个进程内队列。Web API 不直接打开串口，也不调用外部 `test` 程序。

### 电机设备适配器

扩展 `DevStepperMotor`：

- 保存型号、地址、方向校准和状态。
- 支持启动、停止、设置目标速度、读取实际速度、读取状态字。
- 正确编码负数的 32 位二进制补码。
- 任一步启动失败时立即尝试停机，并返回失败步骤。
- 仅在回帧验证通过后更新内存状态。

42 型和 57 型先复用通用 CiA402 速度适配器，同时保留协议型号字段，为后续型号差异提供扩展点。

### 原子服务与运行时

新增电机调速原子服务，由 `MarineExecutor` 调用执行器控制接口。`MarineRuntime` 在节点进入运行状态时获取资源锁并启动电机，在参数更新时调整速度，在节点完成、取消、失败或应用停止时释放资源并停机。

每个逻辑执行器采用独占锁。第二个应用请求已占用执行器时返回资源冲突，前端显示占用它的应用，不排队也不覆盖。

运行中换向流程：

1. 写目标速度为零或执行受控减速。
2. 轮询 `606Ch`，确认绝对转速进入停止容差。
3. 超时则停机并报告故障。
4. 写入反向目标速度并更新方向。

### 控制模式与安全

后端启动参数明确选择 `real` 或 `simulation` 模式，禁止通信失败后静默回退。

真实模式下控制能力默认启用。以下操作始终允许：

- 停止单台电机。
- 停止应用所占用的全部电机。
- 全船执行器急停。

急停具有最高队列优先级。急停后禁止新的启动命令，直到操作员在前端明确复位。进程正常退出时对已知运行电机执行尽力停机；无法保证断电或进程崩溃时的软件停机，因此现场急停和驱动器保护仍是硬件保障。

### API

在 `/api/v1/marine` 下增加或扩展以下能力：

- 获取电机执行器列表、绑定、型号、在线状态、实际速度和占用者。
- 获取与更新电机原子服务实例参数。
- 启动、停止和动态更新运行中的电机节点。
- 全局急停与急停复位。
- 获取真实/模拟模式和控制可用状态。

更新接口验证应用所有权和资源锁，使用明确的 400、409、423、502、504 等错误响应表达参数错误、资源冲突、急停锁定、设备异常和通信超时。

## 前端体验

### 任务编排

原子服务库新增“电机调速控制”。加入编排后，右侧参数面板显示：

- 执行器下拉框：机舱排烟风机、消防水泵、舱底排水泵。
- 转速数字输入与滑杆：`1～500 rpm`，默认 `200 rpm`。
- 正转/反转选择。
- 持续时间。
- 可展开的高级参数：加速度、减速度和设备方向校准展示。

应用保存后完整保留这些参数。校验错误就地显示，不允许生成无效应用。

### 应用运行

每个电机节点显示目标转速、实际转速、方向、运行/停止/换向/离线/故障状态、物理绑定和占用情况。实时数据来自后端，不根据动画进度虚构 rpm。

运行页允许在 `1～500 rpm` 内动态调速、受控换向和停止。页面固定显示当前为“真实设备”或“模拟演示”，真实模式使用醒目的状态标志。全局急停固定在显眼位置，并要求二次确认。

数据流动画展示：应用运行节点 → 电机调速原子服务 → 逻辑执行器 → 型号适配器 → 对应物理电机。流动状态随命令下发、回执和实际速度更新变化。

## 故障处理

- 电机离线、异常响应、CRC 错误或连续超时：停止对应任务，尽力停机，释放业务运行但保留故障信息，等待人工处理。
- 电机重新上线：更新为可用，不自动恢复运动。
- 应用取消或浏览器断开：后端运行时负责停机，控制不依赖前端页面存活。
- 同一电机资源冲突：拒绝后来的控制请求，现有运行不受影响。
- 参数越界：前端提示，后端再次拒绝。
- 网关重启：未完成运行标记为中断，电机状态重新读取；在确认状态前不自动启动。

## 持久化与审计

应用保存原子服务实例参数；设备仓库保存逻辑绑定、型号、方向校准和版本号；运行状态不作为重启后自动恢复运动的依据。

每次真实控制记录：时间、操作员、应用、运行实例、节点、逻辑执行器、物理地址、型号、目标参数、命令步骤、回执、耗时和结果。审计日志不得记录为成功，除非设备回帧验证通过。

## 测试与验收

### 自动化测试

- 参数 JSON 往返保持转速、方向、加减速度、执行器和持续时间。
- 拒绝 `speedRpm` 超出 `1～500`、非法方向和未知执行器。
- I32 正负速度编码正确。
- 启动序列顺序正确；中间步骤失败会停机并返回具体错误。
- 动态调速不重复执行完整使能序列。
- 换向必须先检测到零速。
- 同一执行器的第二个应用收到资源冲突。
- 取消、完成、失败和急停都释放资源并触发停机。
- 急停状态拒绝启动，但允许停止；复位后恢复启动能力。
- 模拟模式和真实模式不会自动互相切换。
- API 返回正确状态码和结构。

### 实机验收

对 `0x02`、`0x0E`、`0x0F` 分别执行：

1. 以 `200 rpm` 正转启动，核对实际转速和方向。
2. 在线调整至 `300 rpm`，核对 `606Ch`。
3. 受控切换反转，确认先停后反向。
4. 单台停止。
5. 三台并行运行后全局急停。
6. 拔出一台设备，确认离线和任务失败；重新接入后不自动旋转。
7. 两个应用竞争同一电机，确认第二个应用被拒绝。

验收要求：每条真实指令均有正确地址和功能码的有效回帧；实际速度在合理稳定时间内接近目标值；任何取消、故障或急停场景不留下软件认为仍在运行的电机节点。
