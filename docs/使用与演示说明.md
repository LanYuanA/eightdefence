# 船舶软件定义平台使用与演示说明

本文用于在麒麟系统上启动、操作和讲解本项目。平台以民用舰船为背景，展示两类软件定义能力：**软软解耦**（用原子服务组合应用）与**软硬解耦**（不中断应用逻辑地替换 RS485 电机）。

## 1. 项目内容与演示边界

### 1.1 四层结构

平台按以下结构组织，现场讲解和数据流图均使用这一顺序：

1. **应用层**：面向船舶任务，例如检修保障、消防联动、环境调节。
2. **原子服务层**：可复用的业务能力，例如态势判断、报警联动、电机调速控制 M01。
3. **设备抽象层**：稳定的逻辑执行器标识与能力接口，例如 `EXHAUST-FAN-01`；应用不直接使用串口地址。
4. **态势感知与执行器硬件层**：温湿度、烟雾、水浸等传感器和三台 RS485 电机，处于同一底层。

传感器用于态势感知，不作为需要替换控制的抽象设备。电机由设备抽象层屏蔽型号、厂商和 RS485 地址差异。

### 1.2 电机资源

| 设备 ID | RS485 地址 | 型号 | 页面名称 | 初始逻辑执行器 |
| --- | --- | --- | --- | --- |
| `MOTOR-02` | `0x02` | IDS57-R | 机舱排烟风机 | `EXHAUST-FAN-01` |
| `MOTOR-0E` | `0x0E` | IDS42-R | 消防水泵 | `FIRE-PUMP-01` |
| `MOTOR-0F` | `0x0F` | IDS42-R | 舱底排水泵 | `DRAIN-PUMP-01` |

M01 可设置 1～500 rpm、正转/反转、加速度和减速度。真实模式下，目标速度、实际 RPM、在线状态和占用者由后端读取和管理。

### 1.3 安全说明

- 真实电机必须由现场人员确认周边无人员、无机械干涉后再启动。
- 正常网关模式会访问 `/dev/ttyS9` 并下发真实 RS485 指令；`--marine-demo` 不访问串口。
- 紧急情况下，使用应用运行界面的“急停”，或停止网关进程并按现场规程处置。
- 硬件解耦页面中的“保护暂停当前电机”会真实停止当前 M01 任务使用的电机；它不伪造串口离线。

## 6. 场景一：软软解耦与按需生成应用

### 6.1 场景目的

展示船舶任务不再是固定软件。业务人员按任务需要，从原子服务库选取服务，通过顺序和并行关系快速组合出新的应用；应用生成后拥有独立可点击页面，并可和其他应用同时运行。

### 6.2 推荐讲解口径

“船上原有感知、执行与控制能力被封装为可复用原子服务。面对不同任务，不必重新开发一整套应用，只需按订单组合已有能力；新的应用生成后运行在同一个软件基座中，并可以与其他应用并行运行。”

### 6.3 操作步骤

1. 打开首页，进入“软件组合”。
2. 查看左侧原子服务库。可在下拉列表中选择服务，也可以将服务卡拖入中间的任务编排区。
3. 将服务放入同一阶段，表示**并行**：该阶段内服务同时运行，全部完成后才进入下一阶段。
4. 将服务放入不同阶段，表示**顺序**：上一阶段完成后再执行下一阶段。
5. 在服务节点中设置态势判断条件和阈值。例如温度、烟雾或水浸达到设定条件后触发后续能力。
6. 使用预设组合，或按以下方式演示：
   - 选择第 1、2、3 个服务，生成一个检修保障应用。
   - 再选择第 2、3、4 个服务，生成另一个船舶任务应用。
7. 点击“生成应用”。系统会显示应用创建过程、服务复用数量与新增应用页面。
8. 在应用列表中点击新生成的应用，进入应用运行页面。
9. 观察数据流图：底层态势感知数据进入原子服务，再进入应用；应用的控制命令经设备抽象层下发到底层执行器。流动粒子表示数据或控制方向。
10. 返回软件基座并启动另一个应用，说明多个应用可同时运行。

### 6.4 M01 电机原子服务操作

真实模式下，M01 是电机调速控制服务。

1. 在任务编排中加入 `M01 电机调速控制`。
2. 选择逻辑执行器，例如 `EXHAUST-FAN-01`。
3. 设置转速、方向、加速度、减速度和运行时长。建议首轮演示使用：
   - 转速：`200 rpm`
   - 方向：正转
   - 加速度：`10`
   - 减速度：`10`
   - 时长：`30 秒`
4. 生成并启动应用。
5. 在运行页面查看实际 RPM；可在运行中修改目标速度、方向或停止该节点。
6. 演示结束后等待任务自然完成，或点击停止。确认三台电机 RPM 均为 `0` 后再离开现场。

## 7. 场景二：软硬解耦与真实电机替换

### 7.1 场景目的

展示同一应用和同一个 M01 原子服务无需修改，即可从一台故障、停用或不同厂商的电机切换到另一台兼容电机。变化只收敛在设备抽象层的逻辑执行器绑定中。

当前演示允许三台电机互相替换：

- `MOTOR-02 / 0x02 / IDS57-R`
- `MOTOR-0E / 0x0E / IDS42-R`
- `MOTOR-0F / 0x0F / IDS42-R`

### 7.2 演示前准备

1. 以真实设备模式启动网关。
2. 在软件组合页面创建并启动包含 M01 的应用，推荐使用 `EXHAUST-FAN-01`、`200 rpm`、正转、30 秒或更长时长。
3. 观察应用运行页显示实际 RPM，确认任务状态为运行中。
4. 打开“硬件解耦”页面。页面右上角应显示“网关接入”，三台设备卡应显示真实在线状态与实际 RPM。

### 7.3 操作步骤

1. 说明左侧软件调用链保持稳定：应用层、M01 原子服务层、逻辑执行器 `EXHAUST-FAN-01` 都不修改。
2. 指出中间“运行时逻辑绑定”是唯一发生变化的位置；当前绑定为 `MOTOR-02 / 0x02` 时，逻辑执行器的地址细节没有进入应用。
3. 点击“保护暂停当前电机”。
   - 后端先停止运行中的旧电机。
   - 旧任务状态进入保护暂停。
   - 页面显示原任务剩余时长及当前绑定。
4. 在另一台在线、静止且未被占用的电机卡片上点击“检测候选设备”。
   - 系统校验候选电机的在线状态、实际 RPM 和占用者。
   - 校验通过后，页面进入“等待人工确认”。
5. 点击“操作员确认切换”。
   - 后端更新 `EXHAUST-FAN-01` 的设备抽象绑定。
   - 原 M01 任务自动恢复，不改变应用 JSON、原子服务配置、速度、方向、加减速度或剩余时长。
   - 页面显示新绑定地址和新的实际 RPM。
6. 指出页面指标：应用修改为 0、原子服务修改为 0；只有设备抽象层绑定更新。
7. 等待任务结束或回到应用页面停止任务，确认所有电机为 0 rpm。

### 7.4 真实替换判定规则

候选电机必须同时满足：

- 后端可读到在线状态。
- 实际 RPM 为 0，且不在运行。
- 没有被其他任务占用。
- 网关未处于急停锁存状态。

若恢复失败，系统会停止目标电机并回滚到原绑定，任务保持保护暂停。若保护暂停时旧电机未能确认停止，系统不会进入切换流程。

### 7.5 推荐讲解口径

“这里三台电机的地址、型号甚至厂家可以不同。应用只调用排烟风机逻辑执行器，M01 只使用统一的调速能力接口。设备发生故障或更换时，不重写应用、不重写原子服务，只在设备抽象层把逻辑执行器重新绑定到通过校验的物理设备，原任务按原参数自动恢复。”

## 8. 常见问题与处理

### 页面显示“演示模式”

- 确认网关进程仍在运行。
- 使用 `http://127.0.0.1:8080/` 打开，不使用 `localhost`。
- 执行 `curl http://127.0.0.1:8080/api/v1/health`。无法返回时，重新启动网关。

### 页面显示网关接入，但电机离线

- 检查电机供电和 RS485 线缆。
- 检查 `/dev/ttyS9` 是否存在、当前用户是否有串口权限。
- 确认没有第二个程序同时占用串口。
- 通过 `curl http://127.0.0.1:8080/api/v1/marine/motors` 查看具体电机的 `online` 与 `actualRpm`。

### 点击保护暂停提示没有运行中的真实 M01 任务

硬件解耦页面不会擅自启动电机。先到“软件组合”创建并运行含 M01 的应用，再返回硬件解耦页面。

### 候选设备无法检测或无法切换

候选电机可能离线、RPM 不为 0、正被其他任务占用，或者系统处于急停状态。停止占用任务、确认候选静止且在线后重试。

### 紧急停止

在应用运行页面执行急停。急停为锁存状态，必须由操作员明确复位后才能重新控制电机。发生物理异常时，优先按现场安全规程断电或处置。

## 9. 演示结束检查

1. 停止所有运行中的应用。
2. 查询 `GET /api/v1/marine/motors` 或查看页面，确认三台电机实际 RPM 为 0。
3. 关闭网关进程：在其终端按 `Ctrl+C`。
4. 如使用静态服务器，也按 `Ctrl+C` 停止 Python 服务。

## 10. 关键接口（便于排障）

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/health` | 网关、急停和真实/模拟模式状态 |
| `GET /api/v1/marine/motors` | 三台电机在线、RPM、占用状态 |
| `GET /api/v1/marine/hardware-decoupling` | 硬件解耦会话与绑定状态 |
| `POST /api/v1/marine/hardware-decoupling/protect` | 保护暂停当前真实 M01 任务 |
| `POST /api/v1/marine/hardware-decoupling/candidates/{deviceId}` | 校验候选设备 |
| `POST /api/v1/marine/hardware-decoupling/switch` | 人工确认后绑定并自动恢复 |
| `POST /api/v1/marine/emergency-stop` | 电机急停 |
| `POST /api/v1/marine/emergency-reset` | 急停复位 |
